Política de Privacidade

Válida a partir de 05 de maio de 2025

A Vigilum, Pessoa jurídica de direito privado, leva a privacidade do usuário a sério e zela pela segurança e proteção de dados de todos os seus clientes, parceiros, fornecedores e usuários.

Ao utilizar nossos serviços, o usuário concorda com os termos desta Política de Privacidade.

1. Definições

ANPD — Autoridade Nacional de Proteção de Dados.
Titular — Pessoa natural a quem se referem os dados.
Dados Pessoais — Informações que identificam uma pessoa.
LGPD — Lei Geral de Proteção de Dados.

2. Uso de Dados

A Vigilum utiliza dados pessoais para melhorar a experiência do usuário, prestar serviços, cumprir obrigações legais e garantir segurança operacional.

3. Dados Coletados

Nome, telefone e e-mail.
Dados de navegação e endereço IP.
Informações fornecidas pelo usuário.

4. Compartilhamento

Os dados poderão ser compartilhados com parceiros e prestadores de serviço quando necessário para execução das operações.

5. Cookies

Utilizamos cookies para melhorar a navegação, desempenho e experiência do usuário.

6. Direitos do Usuário

Solicitar acesso aos dados.
Corrigir informações.
Solicitar exclusão dos dados.
Revogar consentimentos.

7. Segurança

A Vigilum adota medidas técnicas e administrativas para proteger os dados pessoais.
